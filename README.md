# NET / OPS · v0.9 正向場景與 42U 機櫃

以正向俯視的上帝視角，從零建置公司網路的電腦版教學遊戲；地圖沒有斜向投影。選規模、採購、供電、接線，用 Cisco 風格 CLI 設定，再處理同仁亂插線、網孔氧化、線材間歇斷線與主機老化。

[下載最新版 ZIP](https://github.com/rechteab2133589664/-/archive/refs/heads/main.zip)，完整解壓縮後以電腦 Chrome 或 Edge 開啟 `index.html`。不需安裝套件、登入或連網。開發預覽可在資料夾執行 `python3 -m http.server 8000`，開啟 <http://127.0.0.1:8000/>。

## 桌面版操作

建議 1366×768 以上。頂部資訊、左側教學、中央場景及底部事件列固定在視窗內，主要操作不需要捲動整個網頁。資產清單提供搜尋及上一頁／下一頁；工單和架構說明也以分頁呈現。

- 地圖以綠燈表示正常、紅燈表示異常；未供電、未完成連線或組態的設備也會亮紅燈。間歇性故障在修復前持續紅燈，不會因暫時 UP 誤判為正常。
- 點設備直接診斷、設定或維修；點工作站後可以切換主機、網路線及網孔。
- 拖曳或 WASD／方向鍵平移鏡頭，＋／－或滾輪縮放，Home／公司總覽顯示全圖，Esc 關閉設備面板。縮放不一定要使用滾輪。
- 採購後先逐台上架，再供電與接線。42U 標準機櫃提供 U 位編號、固定導軌、螺絲孔、配線架、理線器、PDU、設備前面板與狀態燈；網路設備由上往下安裝，較重的 UPS 預留最底部 U3–U1。
- 右上「42U 機櫃」開啟放大前視圖，可按「安裝下一台設備」，或選擇已裝設備直接管理。每台設備上架進度都會存檔；原有已供電的公司自動沿用完整上架狀態。空 U 位保留給未來擴充，本版依本關設備清單安裝。
- 左側教學一步一步帶領施工；「建置流程」可查看完整步驟。採購及施工階段也會有員工在辦公區走動。
- 人物為原創 Q 版，有名字、不同髮型、服裝、膚色與眼鏡，沿辦公區走道行走，不穿越機房或桌子；暫停會停止人流動畫與設備老化。
- CLI 維持深色等寬字終端機、提示符號、模式與原有指令引擎。左側以「指令教學／地址與驗證」切換，右側輸入列及操作按鈕固定可見；歷史輸出仍可獨立捲動。
- 診斷後恢復正確網孔或更換該項故障設備，再重新驗收。故障練習、時間倍率及快轉可練習不同維護情境。

醫院模式與相關資源已移除，遊戲只保留公司模式。既有公司存檔保留；資料與鏡頭位置儲存在目前瀏覽器，可匯出 JSON 留存。更換瀏覽器、網址或本機路徑可能無法讀到原進度。

## 規模與模擬範圍

1–10,000 人，依規模推薦小型單台交換器、中型折疊核心或大型三層架構。每人一個有線端點，加 20% 資料埠預留；人數分界是教學設定，不是 Cisco 工程規範。

設備採購量按整家公司計算，畫面教一個代表區域；逐一追蹤最多 12 個工作站、12 台接入設備及第一組彙聚與核心，其餘資產暫視為健康。工作站故障影響一人，接入故障影響實際分配員工，第一組彙聚最多 960 人，主核心全公司；同一人不重複計數。

CLI 為 Catalyst 風格教學子集，非 Cisco 韌體。未教的邊界／彙聚設定由場景模型套用，驗收是狀態檢查而非封包模擬。未設定的 HSRP／StackWise、OSPF、STP 不會被假設生效。設備價格、壽命及故障機率是加速遊戲模型，非真實廠商報價、保固或可靠度預測。
