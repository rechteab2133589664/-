# NET / OPS · v0.12 點地板自選機櫃位置

電腦版網管教學遊戲，恢復 3D 斜角上帝視角。保留滾輪與＋／－縮放，整層可用場地已擴大到原本約三倍。機房依照片參考改為黑色網孔櫃體、自選機櫃佈局、架空地板、送風柵與橘黃上方線槽。主要操作固定在桌面視窗內，保留 Q 版員工、紅綠狀態燈與原本的 Cisco 風格 CLI。

[下載最新版 ZIP](https://github.com/rechteab2133589664/-/archive/refs/heads/main.zip)。完整解壓縮到新資料夾，以電腦 Chrome 或 Edge 開啟 `index.html`。不需安裝套件、登入或連網；採購網站與訂單為遊戲內模擬。建議 1366×768 以上。

開發預覽：在遊戲資料夾執行 `python3 -m http.server 8000 --bind 127.0.0.1`，開啟 <http://127.0.0.1:8000/>。

## 點地板建立機櫃

新機房建好後是空房，已購買的空機櫃留在庫存，位置由玩家決定。

1. 點機房內的空白地板，出現該位置的機櫃與維護走道預覽。
2. 右側選「使用庫存建立機櫃」。確認才會消耗一座庫存，不會再次扣採購費；也可以取消或點另一塊地板換位置。
3. 點建立好的 3D 機櫃，再點空白 U 位、從設備庫存上架。
4. 已有機櫃可以在櫃內畫面按「搬移本櫃」，返回地板選新位置；櫃號、U 位、設備及組態都會保留。

位置會對齊地板的細分格點，並檢查邊界、重疊、機櫃正面走道、空調及出入口保留區。綠色預覽可放置，紅色預覽會顯示原因並停用確認。位置、庫存與搬移結果都會存檔。舊版本的自動排列會依原座標遷移，不會清掉已建好的機櫃或櫃內設備；可以再自行搬移。

搬移目前是佈局編輯，會保留既有網路狀態，尚未模擬實際搬遷時的線長與停機流程。

## 保留的 CLI 與壽命修正

VLAN 模式可以直接輸入 `int gi1/0/1` 進入介面設定，不必先 `exit`。介面／範圍／VLAN 之間的選擇指令也支援直接切換，並維持 Tab、`?` 與錯誤輸入的模式保護。

設備改用以下預期使用年限，每個遊戲年為 365 日；時間倍率只加快日曆，不會把年限縮成幾十天。

| 設備 | 預期年限 |
| --- | --- |
| 電腦 | 6 年 |
| 網路線 | 15 年 |
| 網孔／資訊插座 | 20 年 |
| 接入交換器 | 10 年 |
| 核心／彙聚交換器 | 12 年 |

健康度依實際使用時間緩慢下降。自然磨耗按月檢查，半個使用年限之後才逐漸增加機率；到期後仍需診斷、更換並驗收。手動故障練習會明確注入情境，其中「模擬 6 年電腦到期」只改變指定 PC 的設備年齡。

資產表、設備面板與巡檢證據都以年限顯示；時鐘顯示年／日，提供「快轉 1 年」及「1 日／秒」倍率。舊存檔保留已用時間、組態、預算與機櫃位置，改套新年限；撤銷原短期模型造成的過早到期告警，保留其他故障及刻意啟動的老化練習。這些是遊戲的汰換／老化模型，不代表製造商保固或每台硬體的實際可用年限。

## 新建置流程

1. 輸入公司人數、選擇網路架構，跟隨左側教學。
2. 點地圖上的管理電腦，或工具列「管理電腦」，開啟桌面與瀏覽器。這台電腦已提供獨立行動網路，不必先建好公司網路。
3. 在採購網站確認推薦清單，選購 3–12 座機櫃後下單。費用從遊戲預算扣除，設備立即送達庫存。訂單可從管理電腦再次查看。
4. 比較三個機房候選位置。A 西側內側獨立室為推薦地點，容納十二櫃；B 西北窗邊、C 西南服務空間各容納八櫃。選擇位置後確認建設，按該地點費用扣款；地圖上的機房位置會隨選址改變，建好後由你在房內點地板放機櫃。
5. 點機房地板選位置，使用庫存建立機櫃；至少建立一櫃即可開始上架，不必一次把所有機櫃擺完。點 3D 機櫃，或按「選機櫃」選一櫃，進入該櫃的 42U 前視畫面。
6. 點任一空白 U 分隔，右側打開庫存。選設備、檢查佔用的連續 U 位，再按「確認上架到選定 U 位」。設備會從共用庫存移除，可自由分配到不同機櫃與不同位置。多 U 設備不可越界、重疊，同一設備不能重複上架；UPS 建議放在底部。
7. 本區必要設備上架完成後，依教學供電、逐段接線，進入 Console 完成 VLAN、上聯與地址設定。左側可切換「指令教學／地址與驗證」，右側終端機的提示符號、輸入及保存行為保持原版。
8. 保存、驗收後開始營運。處理同仁接錯線、插座氧化、線材間歇故障與主機老化；先診斷、再修復，最後重新驗收。

## 操作與存檔

- 拖曳或 WASD／方向鍵平移鏡頭；「機房」「辦公區」切換觀看位置，滾輪或＋／－縮放，Home／「全區」顯示整層場地。
- 綠燈表示正常，紅燈表示未就緒或異常；間歇性故障在修復前持續紅燈。點工作站可切換主機、線材與網孔。
- 資產表可搜尋／分頁，工單及庫存也有分頁。CLI 歷史輸出仍可獨立捲動。
- Q 版員工會沿辦公區走道活動，不會穿過桌子或進入機房；暫停會停止人流動畫與設備老化。
- 訂單、機房地點、機櫃與 U 位、組態和維修進度都會儲存在目前瀏覽器。原有已上架／供電的公司會保留進度並遷移到多機櫃格式。可匯出 JSON 留存；更換瀏覽器、網址或本機路徑可能看不到原存檔。

## 模擬範圍

目前是擴大的單層場地，沒有後期樓層解鎖；原本空間小是地圖範圍限制。支援 1–10,000 人，推薦小型單台交換器、中型折疊核心或大型三層架構。每人一個有線端點，加 20% 資料埠預留；人數分界是教學設定，不是 Cisco 工程規範。

採購清單與費用按整家公司計算。可逐台操作的庫存為本區代表機房設備，最多包含 12 台代表接入設備；其他區域以批次部署模型處理。持續追蹤最多 12 個工作站、12 台接入設備及第一組彙聚與核心，其餘資產暫視為健康。本關以這些代表機櫃練習上架，整間公司的其他設備另按容量計算。機房地點的費用、容量與實際位置有作用；日照、防水及空調風險目前是規劃提示，尚未另行模擬災害。

工作站故障影響一人，接入故障影響實際分配員工，第一組彙聚最多 960 人，主核心全公司；同一人不重複計數。CLI 為 Catalyst 風格教學子集，非 Cisco 韌體。未教的邊界／彙聚設定由場景模型套用，驗收是狀態檢查而非封包模擬；未設定的 HSRP／StackWise、OSPF、STP 不會被假設生效。價格、壽命和故障機率是遊戲模型，非真實報價或保固。
