# NET / OPS · v0.6 從零開始的網管生涯

電腦版公司網管教學遊戲。選公司人數與架構，從空辦公室採購、供電、逐段接線，再透過 Cisco 風格 Console 設定 VLAN、上聯、閘道與 DHCP，保存並驗收。正式營運後，處理同仁接錯網孔、線材間歇故障、插座氧化和主機老化。

## 直接下載與開啟

[下載最新版 ZIP](https://github.com/rechteab2133589664/-/archive/refs/heads/main.zip)，**完整解壓縮後，用電腦的 Chrome 或 Edge 開啟 `index.html`**。不需要安裝套件或連網；這是瀏覽器遊戲，不是 Windows 執行檔。原醫院版保留在 `hospital.html`，也可從公司版右上角開啟。

建議 1366×768 以上。開發預覽：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

然後開啟 <http://127.0.0.1:8000/>。

## 公司版玩法

1. 輸入 1–10,000 人，查看推薦：小型單台交換器、中型折疊核心、大型三層架構。數量包含每人一個有線端點與 20% 資料埠預留；這些人數分界是教學選擇，不是 Cisco 的工程規範。
2. 左側教學卡依序帶領採購、供電、逐段連接指定設備。先點接線第一端，再點另一端。
3. 開啟 Console，逐條輸入指令，或使用明確標示的逐行／整台教學示範。中大型需完成核心與接入兩台教學設備。套用正確閘道及 DHCP，再保存全部組態。
4. 驗收後開始營運。可暫停、切換時間倍率、快轉一天，或安排個別故障練習。
5. 告警與工單選「前往現場」，角色會走到資產旁。先巡檢收集證據，再接回正確網孔或更換該項故障設備，最後重新驗收。更換主機不會消除另一條壞線的問題。

WASD／方向鍵移動，Shift 快跑，E 巡檢，點走道自動帶路。資產頁顯示健康度、使用日數與模型壽命。狀態只在公司營運時隨時間推進；按「暫停」仍可走路與維修。

進度自動保存在目前瀏覽器，與醫院版使用不同儲存鍵；可匯出 JSON 留存。更換瀏覽器、網址或搬動本機檔案可能看不到原存檔。

## 模擬範圍

- 裝置以 Cisco 型號與 Catalyst 風格 CLI 教學子集呈現，支援模式、縮寫、Tab、`?`、歷史指令、running/startup config。不是 Cisco 韌體，也沒有宣稱 99% 相似度。
- 圖上是一個代表辦公區。價格與採購數按整家公司規模計算，逐一追蹤最多 12 個工作站、12 台接入交換器、第一組彙聚與核心。其他區域的資產暫視為健康。
- 代表工作站故障影響一人；接入故障影響其實際分配員工；第一組彙聚影響最多 960 人；主核心故障影響全公司。多個故障影響同一員工不會重複計數。
- 目前未教的路由器、防火牆、彙聚設備由場景模型套用設定。驗收是狀態模型檢查，不是真實封包模擬；未建置的 HSRP／StackWise、OSPF 或 STP 不會被假設已生效。
- 硬體壽命為加速遊戲模型，並非現實保固或可靠度預測。間歇故障確實切換 UP／DOWN，短暫恢復仍保留告警。

## 本次現場任務

1. 跟著畫面上方施工教學卡，按「帶我過去」走到 UPS 並開啟供電。機櫃 PDU 電源已預接。
2. 在配線架選天花板線槽、開始穿線，走到護理站插座完成降線。
3. 兩端分別完成 T568B 線序練習，再於牆面插座執行 1–8 基礎驗線。永久鏈路未驗線通過，Ping 不會成功。
4. 教學會逐條帶著接六段 Cat6 跳線，並標亮該點的網孔。
5. 用隨身 Console 線與筆電設定核心、接入設備的 VLAN、SVI、Trunk 與 Access VLAN，儲存設定。
6. 啟動工作站、設定靜態 IPv4，執行 `ping 10.10.10.1` 驗證。
7. 驗收後可拔除接線，觀察測試失敗，再練習復原。

## 模擬範圍

本版實作：可碰撞的等角院區、角色移動、尋路、近距離互動、設備面板、網孔接線／拔線、長度檢查、供電、簡化 Console CLI、靜態 IPv4，以及由實際遊戲狀態決定成敗的閘道 Ping。

- 路由器與防火牆已有實驗室預設組態，本關不編輯其完整路由與政策。
- 新遊戲需完成配線架 P1 到牆面 J1 的線槽規劃、穿線、兩端 T568B 線序練習及 1–8 基礎驗線。P2–P4、J2 是未接通的備用孔。
- 舊版存檔保留已預埋鏈路；可按「埋線教學」重新練習，不會清除設備組態、IPv4 或現有跳線。
- 線序練習顯示邏輯針腳 1–8，不是 IDC 端子的實物佈局。真實資訊模組需依廠商色碼打線；簡單線序／導通測試不能取代 Cat6 認證測試。
- CLI 為原創的 Catalyst 風格子集合，不含 Cisco 韌體；不宣稱 99% 相容。實作模式權限、縮寫、Tab、`?`、VLAN／SVI／Access／Trunk、介面範圍、介面啟停、描述、hostname、`do show`、running／startup-config、互動存檔及 reload。
- 螢幕呈現訓練關卡用介面子集，並非實體機種所有埠數的複製。OSPF／BGP、ACL、完整 STP／DTP、AAA、SSH 等仍未實作；PortFast 只保存設定，不模擬 STP 狀態機。
- 工作站閘道驗收仍以本關 IPv4 目標為準。SVI up/down 取決於 VLAN 與有效介面；shutdown、Trunk allowed VLAN 與相關 native VLAN 設定會影響連線。
- 本地同 VLAN 工作站 Ping 閘道不依賴 ISP，也不要求先儲存設定；全工程任務另外要求完成全部配線與存檔。
- `copy run start` 需按 Enter 確認檔名；`write memory` 可直接儲存。`reload` 會詢問是否保存變更，UPS 重新供電會從 startup-config 還原。瀏覽器重新整理則保留目前遊戲現場，不等同設備重開機。
- 線長是場景距離估算；線槽施工目前為步驟模擬，沒有真實纜線物理、訊號衰減、完整封包或臨床應用模擬。
- 尚未加入萬人經營、監控平台、自動化部署；這些需在現場互動核心上繼續開發。
- 不連接任何真實設備，不處理真實病患資料。

## 0.4 人物、招募與醫院運作

### 可辨識的人物與對話

角色有眼睛、眉毛、鼻子、嘴巴，並以髮型、膚色、眼鏡、鬍鬚、衣著區分。玩家、助手、醫師、護理師、掛號人員、病患及家屬都有姓名。玩家可在「我的角色」改名與切換外觀。靠近人物按 E 可以對話；點遠處人物會先走到附近再交談。與醫護或病患交談時，相關對話／服務會暫停，其他人仍照常活動。

### 招募與指派

- 提供 6 位不同外觀與熟練度的應徵者；資訊室最多招募 4 位助手，並非整間醫院的人數上限。
- 初始招募訓練預算為 NT$60,000，費用只扣一次；沒有模擬月薪、解雇與經濟成長。
- 助手在門診大樓 1F 資訊室報到，使用與玩家相同的實體碰撞及尋路。
- 可派工作：設備巡檢、依配線圖接下一段跳線、永久鏈路基礎驗線、核心／接入交換器 running-config 快照備份。
- 接線會先走到起點、操作並帶線到終點；目標孔被占用、線材不足或已有同事施工時會拒絕／停止，不會覆寫原線。
- 線材會為助手保留，完成工作才成為實際跳線；取消工作會釋放未接妥的線材。工作結果、預算、進度與備份都會存檔。
- 驗線需先完成線槽、穿線、兩端打線；助手會巡訪配線架與牆面插座，成功後更新真實驗收狀態。
- 組態備份會保存當下的 running-config，與 startup-config 分開，不會自動儲存／覆寫設備開機設定。
- 玩家可以取消任務，或離開該棟樓讓助手繼續工作。工作隨遊戲運行推進；未模擬關閉瀏覽器後的離線工作。

### 園區與病患流程

提供 4 棟、9 個可切換樓層：門診大樓 1–2F、兒童醫療樓 1–2F、住院大樓 1–3F、急診大樓 1–2F。各樓層有自己的佈置、人物與狀態；使用園區接駁／電梯選單切換，尚無完整室外道路或實體電梯車廂。

每層初始約 15–20 位醫護及病患，兒科另有兒童與家屬，住院樓另有床位病患。門診病患實際沿可通行路線移動，依序等候掛號、辦理登記、診間報到、候診、進入診間、完成服務並離院。掛號與各診間一次服務一人，等待佇列依序前進；離院後會產生新病患，姓名外觀不會固定重複同一批。動態列及紀錄反映當下流程，不是固定數字或單純動畫。

已開啟樓層會持續運作，切換樓層不會清掉人物或助手。住院與急診採相同基礎服務流程的簡化版本，另配置住院病床、護理巡視、兒童遊戲區或觀察床。本版沒有醫療診斷、治療決策、真實檢傷分級、病歷、完整 HIS／PACS，既有門診流程也尚未與施工區的護理工作站網路故障連動。

### 存檔相容

舊版存檔會補上人物、招募及主樓 1F 的院區資料，保留原本線材、IP、Cisco 組態與施工進度。新資料仍使用原本的本機存檔鍵；匯出 JSON 會包含助手、園區位置、人物流程與組態快照。

## 0.5 動線與對話重排

### 主樓平面與門禁

- 西北側為資訊機房，中央西側為資訊室，皆為刷卡管制區；玩家與資訊室助手持有通行權。
- 西南側設 101 家醫科與 102 一般內科，接上南側公共走廊。病患從掛號區經公共走道、診間報到及候診區前往看診，不再透過資訊室或機房。
- 機房入口顯示門禁門、讀卡機、禁區標示；授權角色靠近時門會開啟。即使門已為職員開啟，病患仍沒有穿越權限。
- 病患、家屬與臨床人員使用公共尋路政策；玩家和資訊室助手使用職員政策。路徑快取依權限分開，實際移動也重新檢查區域權限，不只靠關門或標示。
- 舊存檔的設備組態、線材、助手與已完成工作保留。舊版 NPC 動線會重新安排；病患回到公共區重新排隊、保留既有完成次數，清掉穿越舊隔間的路徑。若角色剛好位於新增家具內，會安置到大廳。

### 同仁閒聊與病患問路

醫師、護理師、掛號同仁與資訊室助手有工作、休息、興趣等不同閒聊分支，同一對話可繼續聊其他內容。病患與家屬不會解說整個醫院流程或遊戲介面，只談自己的掛號科別、診間、初診／回診、報到與候診狀況。

每位門診病患保存自己的就診科別及診間，對話、頭頂提示、動線及看診目標使用同一份資料。部分初到院區的病患會問路；按 E 交談後選「我告訴你怎麼走」，會實際解除迷路狀態並前往正確報到點。未幫忙時會由服務台稍後指引，不會無限卡住。指路時會分別顯示玩家的路線說明與病患簡短的道謝。

新增檢查涵蓋公共／職員權限隔離、門開啟時仍不可尾隨、九個樓層人流每一步都不踏入禁區、診間可達、舊路徑遷移、同仁閒聊、病患個人科別及問路狀態變更。這仍是簡化的醫院營運與預寫對話，沒有真實病歷或醫療診斷。
